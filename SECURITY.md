# Security

## How to report a security problem

Please report it privately, never in a public issue.

- If this repository's Security page offers "Report a vulnerability", use it. Only the author sees
  what you write there.
- If it does not, open an issue titled "Security: please contact me" and put no details in it.
  The author answers you privately.

## What counts

Anything that could lose or expose a player's data, or make RimOxide run something the player did
not ask for.

RimOxide loads and decodes pictures from the web when it shows a mod's description.
If a picture makes RimOxide crash or misbehave, please report it privately, as described above, with the mod's name.

## Which versions get fixes

Only the newest beta. Download it from the Releases page before you report.
